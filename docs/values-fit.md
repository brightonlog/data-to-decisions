# Revolut 인재상 → 포트폴리오 증거 매핑

## 1. 공식 가치 5개 (revolut.com/our-culture 기준)
| 가치 | Revolut 원문 요지 | 면접에서 보는 것 |
|---|---|---|
| Never Settle | "10x people"를 위한 회사. good enough에 안 멈춤. 1등 아니면 안 됨 | 스스로 세운 높은 목표와 달성. 완료한 과제가 아니라 올린 기준 |
| Dream Team | 프로 스포츠팀. 올스타만. 소수 정예 > 다수 평균. 목표 달성 > 좋은 사람으로 보이기. 솔직한 피드백 | 준 피드백·받은 피드백. 남의 기준을 올린 경험 |
| Think Deeper | 논리·이성·상식이 모든 결정에 우선. 문제 정의에서 시작, "그게 사실인가? 왜?"를 근본 원인까지 | 케이스에서 해결책 전에 문제 정의·가정 명시 |
| Get It Done | 결과만 봄. 변명 안 들음. 매일 할 일을 알고 해내는 규율. 시작부터 끝까지 오너십. 분석 마비 없이 데이터+상식으로 결정 | 내가 직접 소유한 것. "someone else's job" 없음 |
| Deliver WOW | okay-ish 품질 거부. MVP 아니라 Minimum Lovable Product. 고객 우선 + 단순하게 | 디테일 품질. 내부 고객도 고객 |

내부 인용 두 문장 (Revolut 블로그):
- "말하는 사람보다 일하는 사람이 항상 우선" (Get It Done)
- "직함 상관없이 말이 되면 다 붙어서 실행" (Think Deeper)

## 2. "Hardworker" — 공식 문서 밖의 실제 기준
| 출처 | 내용 |
|---|---|
| Storonsky 인터뷰 | 면접에서 직접 묻는다: "Are you prepared to work hard?". 99.5% 시간이 일. 경쟁적 산업에선 느슨한 문화 안 됨 |
| 문화 페이지 | "매일 뭘 해야 하는지 알고 해내는 규율" |
| Bar Raiser 구조 | 전 경력을 역할별로 훑음. 모든 주장에 2~3단계 더 파고듦. "전 상사가 10점 만점에 몇 점 줄까", "제때 승진했나" |
| QuantumLight 채용 플레이북 (Storonsky 공저) | True/False 스코어카드. 전 매니저가 탑 퍼포머로 봤다는 결정적 증거 요구. 레퍼런스 체크도 Bar Raiser가 직접 |
| 외부 평가 | 높은 강도·장시간·KPI 압박 일관되게 보고됨. 회사는 "더 인간적인" 문화 개편 진행 중 |

결론: 공식 5개 가치 중 Get It Done + Never Settle 조합 = "hardworker". 면접은 말이 아니라 **지속된 행동 기록**으로 확인함.

## 3. 내 증거 매핑
| 가치 | 증거 | 수치 | 상태 |
|---|---|---|---|
| Never Settle | 비STEM 전공에서 SW/AI 과정 자발 선택 → 2,000명 중 2% 코치 선발 | 1,628h / 2% | 확정 |
| Get It Done | 1,628시간 과정 완주. 코치 업무와 포폴 병행. 매일 기록 습관 | 커밋 로그, 일일 기록 | 커밋 로그 쌓는 중 |
| Think Deeper | 케이스 템플릿: 문제정의 → MECE → 가설 → 검증. 가정·한계 명시 | 케이스 3개 | 작성 예정 |
| Deliver WOW | 내부 고객(교육생 800명·코치)용 자동화. 1장 요약 + 부록 구조 | 전후 지표 | 측정 필요 |
| Dream Team | 코치로서 교육생 평가·피드백. 받은 피드백으로 바꾼 것 | 사례 2개 | 정리 필요 |

### 솔직한 공백
- Dream Team: "남의 기준을 올린" 사례 약함. 코칭 피드백 사례로 보강.
- Get It Done: 아직 "끝까지 완결한 프로젝트" 증거가 SSAFY 프로젝트뿐. 포폴 케이스 완성 자체가 증거가 됨.
- hardworker는 주장 불가. **GitHub 커밋 히트맵·일일 기록이 유일한 객관 증거.** 매일 커밋.

## 4. 포폴 반영 방식
| 위치 | 방법 |
|---|---|
| 헤더 한 줄 | 가치 단어 직접 쓰지 않음. 행동으로: "Non-STEM → 1,628h → top 2% → running ops for 800" |
| 정의 섹션 | S&O 정의 3줄 옆에 Revolut 가치 5개와 내 증거 1:1 표 (이 문서 3절 축약) |
| 케이스 | 각 섹션이 가치 하나를 증명: 0~2 = Think Deeper, 3~4 = Get It Done, 5~6 = Never Settle, 7 = Think Deeper(지적 정직), 전체 완성도 = Deliver WOW |
| 사이트 하단 | GitHub 커밋 히트맵 임베드. 설명 없이 |
| 금지 | "열정", "성실", "hardworking" 같은 자기 서술 형용사. 전부 수치·행동으로 대체 |
